# Use Case 10: Agentic Perception-Decision System + Reasoning Faithfulness

## Purpose
The capstone use case of the VLM-Mobility series, synthesizing prior findings into two questions: (1) does chaining multiple specialized VLM "agents" (Perception → Prediction → Planning) actually improve driving-decision quality over a single end-to-end agent, and (2) is the model's chain-of-reasoning actually *faithful* — i.e., does the model's final decision genuinely depend on the upstream textual reasoning it was given, or is it just doing direct visual pattern-matching regardless of what the text says?

## Data
DriveLM-nuScenes fixed 9-frame subset (same 3 scenes × 3 frames used throughout the series). A data-structure discovery was made early: DriveLM's JSON uses uppercase `'Q'`/`'A'` field names (not `'question'`/`'answer'`), and the `con_up`/`con_down` reasoning-graph linkage fields (intended to formally connect QA pairs across perception→prediction→planning) are **null throughout all 887 QA entries** — meaning the originally planned use of DriveLM's built-in reasoning graph for UC10b was not possible and the sub-experiment had to be redesigned around a self-constructed counterfactual test instead.

## Experiment Design
Two sub-experiments with Qwen2.5-VL-7B-Instruct:
- **UC10a — Three-agent pipeline vs. single-agent baseline**: a sequential chain of three role-specific agents (Perception Agent → Prediction Agent → Planning Agent), where each agent's text output becomes part of the next agent's input context, culminating in a final driving decision. Compared against a single-agent baseline that goes directly from image to decision (as in UC9) with no intermediate agents.
- **UC10b — Reasoning faithfulness test (counterfactual)**: redesigned to use UC10a's stored Perception-agent outputs as the "upstream context," then tested the Planning agent's decision under three conditions: **(A)** correct/real perception context, **(B)** counterfactual context (a simple, unambiguous "clear road" description contradicting the actual image), and **(C)** no context at all (pure visual reasoning). If the model is genuinely reading and using the upstream text, decisions should differ meaningfully and appropriately across A/B/C; if it's purely visual, B and C should look similar (both ignoring the fabricated "clear road" text) and diverge from A only when A's text adds real information.

## Results
- **UC10a**: The agent chain showed **higher direction accuracy** than the single-agent baseline (0.222 vs. 0.111) but **lower speed accuracy** (0.111 vs. 0.333) — and the single agent's speed advantage was attributed to a simple deceleration bias rather than genuine understanding, so neither number should be read as a clean "chaining helps/hurts" signal on its own. **Chain coherence dropped sharply** from the perception→prediction stage (0.431) to the prediction→planning stage (0.130), indicating the Planning stage largely **reverts to direct visual reasoning** rather than building on the upstream textual chain.
- **UC10b**: All three conditions produced completely different behavior patterns — condition B (fabricated "clear road" text) led to **100% decision override**: 9/9 frames output accelerate and 9/9 output go-straight, fully ignoring the actual image content (vehicles, red lights, pedestrians visibly present). Condition C (no context, pure vision) produced 9/9 decelerate and 8/9 turn-left. Condition A (real, complex perception text) produced a **mixed, partial response** — decelerate was consistent with C (suggesting speed judgment stayed visually anchored), while direction varied across straight/left/right depending on the frame (some corrected toward the right answer, some not).
- **Overall pattern — complexity-dependent text compliance**: the model shows **100% compliance with simple, unambiguous text** (condition B) even when it directly contradicts the image, but only **partial compliance with complex, realistic perception text** (condition A). Speed judgment proved consistently **visually anchored** (A and C matched on speed across all frames) while direction was **text-intervenable but not reliably corrected toward the right answer**.

## Key Takeaway
This is arguably the series' most important finding: the model is **not simply "ignoring text and only using vision"** (as a naive faithfulness test might conclude) — it will fully override correct visual evidence for simple false text. But it also isn't genuinely integrating complex, realistic reasoning chains — it reverts substantially to vision under realistic conditions. The practical implication for agentic VLM pipelines: **chaining textual reasoning stages adds interpretability but does not reliably add decision quality**, and its influence on the final decision depends heavily on how simple/unambiguous the upstream text is — a risk for real deployment, since realistic perception reports are inherently complex, not simple.
